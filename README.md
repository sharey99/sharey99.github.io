网站：[sharey99.github.io](https://sharey99.github.io/) · 编辑：[Pages CMS](https://app.pagescms.org/)

## 添加或修改一张卡片

1. 刷新 Pages CMS，重新打开本仓库，进入对应栏目。
2. 栏目先显示标题列表：点击某条进入**单张卡片编辑页**；新增时点击 **New / 新建**。
3. 填写“一级标题 · 卡片名称”、简介、日期，以及网址、正文或资源文件。正文段落中的小标题为“二级标题”。
4. 需要调整展示先后时填写“卡片排序”，数字越小越靠前；未填的新卡片放在已有卡片后。
5. 点击 Save。每次只保存当前这一张卡片。等待仓库 Actions 中的 Pages 部署成功，再刷新网站。

不要继续使用旧的“网站收藏与笔记”或顶层数组编辑页面。配置已替换，旧页面若仍开着，请先刷新并从左侧重新进入。后台新建文件使用日期时间加标题作为文件名，中文标题可以正常填写。

## 编辑个人介绍与主页

- 在“关于我”中逐项打开介绍、价值观、优长等编辑页；每次只处理这一块。
- “二级标题”对应页面上的小标题；列表内容与标题分别维护。
- 大五人格只填写 iframe 的 src 地址，也可以关闭卡片；它是一次自测记录。卡片加载时连接第三方服务。[官方嵌入说明](https://bigfivepersonality.me/zh/for-bloggers)。
- “主页 · 全部收藏”可修改开场标题、简介、收藏区标题；“赞赏支持”可改标题和说明。
- 自我介绍、赞赏及页尾只在“全部收藏”显示；切换具体分类会隐藏。

## 文件与部署

每张卡片独立保存，互不覆盖：

```text
_data/
  cards/{tools,fun,games,life,notes}/*.json
  resources/{book,image,video}/*.json
  about/{introduction,values,strengths,challenges,personality,bigfive}.json
  home/{introduction,support}.json
.pages.yml       后台栏目与字段
content.json     Jekyll 汇总模板，不直接编辑
resources.json   Jekyll 汇总模板，不直接编辑
profile.json     Jekyll 汇总模板，不直接编辑
homepage.json    Jekyll 汇总模板，不直接编辑
index.html       公开首页
files/           上传附件
```

继续使用现有 GitHub Pages 的 Jekyll 构建。后台保存单张卡片后，GitHub Pages 自动读取目录并汇总为公开 JSON；新增和删除都会同步，无需手工维护卡片清单。不要添加 .nojekyll。原 11 张收藏 / 笔记卡片、1 张书籍卡片和个人介绍已迁移，原附件路径保持不变。

本地预览使用“临时文件/preview-cms.cjs”，它读取相同目录生成 JSON。直接双击 index.html 或把汇总模板当作纯 JSON 打开，不能完整预览。修改 _data 下的 JSON 即可通过本地服务器预览。

## 资源功能

书籍使用 PDF / EPUB，图片使用 JPG / PNG / WebP / GIF，视频使用 MP4 / WebM。可以填写下载文件名、封面、作者、标签；视频还可添加 VTT 字幕。只能上传有权公开的文件，上传的附件会公开。

书籍卡片直接提供下载与预览；EPUB 支持文字章节、目录、前后章与字号调整，复杂排版以原文件为准。PDF 使用浏览器预览。图片可放大，视频在弹窗播放且关闭后停止。JSZip 3.10.1 的来源与 MIT 许可位于 assets/vendor/。

## 哪些适合放，哪些需要授权

下面的发布建议以你拥有相关权利、符合适用规则为前提。公开可访问、免费、非营利或标明来源，都不是自动转载许可。

| 内容 | 建议发布方式 | 注意事项 |
| --- | --- | --- |
| 自己的笔记、心得、攻略 | 直接写在站内 | 不含他人隐私、保密信息；职务或受托成果先核对权利归属 |
| 网站、作者文章和视频 | 写自己的简介，链接原作者或官方页面 | 不绕过付费、登录等访问限制，不冒充来源 |
| 自制视频 | 优先发布到视频平台，再贴观看链接 | 配乐、画面、配图也需有相应使用权 |
| 有权公开传播的 PDF、EPUB 和资料 | 小文件可提供附件，大文件用合适的平台 | 保留授权依据，核对文档内素材的权利 |
| 获得转载授权或开放许可的作品 | 按具体许可转载或分发 | 核对署名、改编、再分发、商业使用等条件 |
| 公版书籍 | 优先链接可信来源 | 核对地区；译本、注释、插图或整理版本可能有独立版权 |
| 读书摘录和评论中的引用 | 以自己的理解为主，必要时适当引用并注明作者与作品 | 不用大段摘录替代原作；合理使用需结合具体情形判断 |
| 游戏截图、演示与素材 | 写自己的攻略，使用符合发行商政策的素材 | 不自动免授权；留意版本与剧透 |

### 本站不收录

- 未经授权的付费电子书、扫描书、课程搬运、影视和音乐文件。
- 盗版游戏、破解软件、盗用激活码、账号共享或泄露数据库。
- 明知用于提供上述侵权内容的网盘地址、种子、磁力链接和下载合集；只放链接也不自动免责。
- 他人身份证、私人聊天、未获同意的照片和联系方式，以及未授权公开的公司、客户资料。
- 恶意文件、钓鱼页面及其他违法内容。

买过一本电子书或一套课程，一般不等于取得向公众传播的权利。“仅供学习”“侵删”也不能替代授权。授权不明时，先只记录书名、作者和官方购买或阅读入口。

这些是本站收录原则，具体作品仍需核对适用法律和许可。关于权利归属、公开传播、适当引用，参见[国家版权局发布的《中华人民共和国著作权法》](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)。

### 视频、书籍、文件怎么放

- **别人发布的视频**：保存原作者在正规平台上的观看链接，不下载搬运；如需嵌入播放器，先确认平台规则。本版不预加载第三方播放器。
- **自己的视频**：上传至合适的视频平台，再添加链接，避免用 Pages 存大视频。
- **别人出版的书籍**：分享自己的书评、笔记及出版社或授权平台链接；未获许可不提供整本 PDF/EPUB。
- **自己编写且有权公开的文件**：小文件可放在仓库的 `files/` 中；大文件放到你有权使用的存储平台，再添加链接。
- **免费或公版资源**：保留来源并查看许可。Project Gutenberg 主要基于美国版权状态选书，不能据此认为每个版本在所有地区都可自由传播。[该项目版权说明](https://www.gutenberg.org/policy/permission.html)



## 隐私、权利与反馈

公开首页不设置 Cookie，不保存搜索词，不接收访客上传，不嵌入统计和广告脚本。GitHub 托管平台、Pages CMS 后台和外部链接各有自己的日志与隐私政策。后台只向有相应仓库权限的编辑者提供内容写入能力。

原创内容不默认授予整篇转载权；第三方内容遵守相应权利人的许可。本版没有替站主选择代码或文章的开放许可。

纠错入口为 [GitHub Issues](https://github.com/sharey99/sharey99.github.io/issues)，需仓库启用 Issues。请勿在公开反馈中填写敏感个人信息。
