# Sharey99 的个人小站

网站：[sharey99.github.io](https://sharey99.github.io/) · 后台：[Pages CMS](https://app.pagescms.org/)

## 当前后台结构

展开“全部收藏 → 网站收藏”，与“资源书架”一样直接选择子项：

- 聚合导航
- 资源网站
- 工具网站
- 学习网站
- ai相关

点击子项后，右侧先显示该项的卡片列表，再打开或新建一张卡片。保存只影响这一张卡片，不需要再选择“所属子分类”。这些子项固定，不提供新增、删除或继续嵌套的入口。

“首页设置”保留栏目名称、首页标题和介绍编辑。网站收藏五个子项的显示名称和介绍，也可在其中的“网站收藏 · 子项名称与介绍”修改，数量和结构保持固定。后台同步完成后刷新页面。

其他栏目、自我介绍、赞赏和资源文件编辑保持原操作方式。标题和介绍可修改；具体卡片可新增、修改和删除。公开网站在网站收藏下显示这五个筛选项，具体卡片自动归到所在子项。

## 已有网站卡片

Excalidraw、Photopea 已归到工具网站；MIT OpenCourseWare、MDN Web Docs 已归到学习网站；Project Gutenberg 已归到资源网站。卡片文字、链接、日期、顺序及原有附件保持不变。

卡片分别保存在 _data/cards/tools/对应子项目录 中。新增卡片请直接进入所属子项。原资源文件仍在 files/，书籍预览和下载功能保持原样。

## 哪些适合放，哪些需要授权

下面的发布建议以你拥有相关权利、符合适用规则为前提。公开可访问、免费、非营利或标明来源，都不是自动转载许可。

| 内容 | 建议发布方式 | 注意事项 |
| --- | --- | --- |
| 自己的笔记、心得、攻略 | 直接写在站内 | 不含他人隐私、保密信息；职务或受托成果先核对权利归属 |
| 网站、作者文章和视频 | 写自己的简介，链接原作者或官方页面 | 不绕过付费、登录等访问限制，不冒充来源 |
| 自制视频 | 优先发布到视频平台，再贴观看链接 | 配乐、画面、配图也需有相应使用权 |
| 有权公开传播的 PDF、EPUB 和资料 | 小文件可提供附件，大文件用合适的平台 | 保留授权依据，核对文档内素材的权利 |
| 获得转载授权或开放许可的作品 | 按具体许可转载或分发 | 核对署名、改编、再分发、商业使用等条件 |
| 公版书籍 | 优先链接可信来源 | 核对地区；译本、注释、插图或整理版本可能有独立版权 |
| 读书摘录和评论中的引用 | 以自己的理解为主，必要时适当引用并注明作者与作品 | 不用大段摘录替代原作；合理使用需结合具体情形判断 |
| 游戏截图、演示与素材 | 写自己的攻略，使用符合发行商政策的素材 | 不自动免授权；留意版本与剧透 |

### 本站不收录

- 未经授权的付费电子书、扫描书、课程搬运、影视和音乐文件。
- 盗版游戏、破解软件、盗用激活码、账号共享或泄露数据库。
- 明知用于提供上述侵权内容的网盘地址、种子、磁力链接和下载合集；只放链接也不自动免责。
- 他人身份证、私人聊天、未获同意的照片和联系方式，以及未授权公开的公司、客户资料。
- 恶意文件、钓鱼页面及其他违法内容。

买过一本电子书或一套课程，一般不等于取得向公众传播的权利。“仅供学习”“侵删”也不能替代授权。授权不明时，先只记录书名、作者和官方购买或阅读入口。

这些是本站收录原则，具体作品仍需核对适用法律和许可。关于权利归属、公开传播、适当引用，参见[国家版权局发布的《中华人民共和国著作权法》](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)。

### 视频、书籍、文件怎么放

- **别人发布的视频**：保存原作者在正规平台上的观看链接，不下载搬运；如需嵌入播放器，先确认平台规则。本版不预加载第三方播放器。
- **自己的视频**：上传至合适的视频平台，再添加链接，避免用 Pages 存大视频。
- **别人出版的书籍**：分享自己的书评、笔记及出版社或授权平台链接；未获许可不提供整本 PDF/EPUB。
- **自己编写且有权公开的文件**：小文件可放在仓库的 `files/` 中；大文件放到你有权使用的存储平台，再添加链接。
- **免费或公版资源**：保留来源并查看许可。Project Gutenberg 主要基于美国版权状态选书，不能据此认为每个版本在所有地区都可自由传播。[该项目版权说明](https://www.gutenberg.org/policy/permission.html)



## 隐私、权利与反馈

公开首页不设置 Cookie，不保存搜索词，不接收访客上传，不嵌入统计和广告脚本。GitHub 托管平台、Pages CMS 后台和外部链接各有自己的日志与隐私政策。后台只向有相应仓库权限的编辑者提供内容写入能力。

原创内容不默认授予整篇转载权；第三方内容遵守相应权利人的许可。本版没有替站主选择代码或文章的开放许可。

纠错入口为 [GitHub Issues](https://github.com/sharey99/sharey99.github.io/issues)，需仓库启用 Issues。请勿在公开反馈中填写敏感个人信息。
