# 拾趣 · Sharey99 的个人小站

## 资源书架：书籍、图片、视频

资源书架改为实际文件展示，后台有独立入口 **“资源书架 · 书籍 / 图片 / 视频”**。这里不填写网站页面地址。

1. 在 Pages CMS 左侧打开资源书架。
2. 添加条目，填写名称、类型、简介和日期。
3. 在“资源文件”上传或选择文件：书籍使用 PDF/EPUB，图片使用 JPG/PNG/WebP/GIF，视频使用 MP4/WebM。
4. 可选填封面、作者、标签，以及视频的 VTT 字幕。
5. 保存后等待 Pages 部署完成，刷新网站的“资源书架”。

- 书籍：显示封面和简介；PDF 可打开阅读，EPUB 可下载后用阅读器打开。
- 图片：卡片显示缩略图，点击后查看大图，可下载原文件。
- 视频：在页面弹窗中使用播放器播放，可附海报和字幕；关闭弹窗会停止播放。
- 资源文件需要与所选类型一致，视频使用浏览器支持的编码，常见选择为 H.264/AAC 的 MP4。
- 首页支持按书籍、图片、视频筛选。尚未上传资源时显示空书架。

原资源书架的 MIT OpenCourseWare 和 Project Gutenberg 网站入口已移至“好用网站”。已有收藏保留在 `content.json`，资源文件条目单独保存在 `resources.json`。

本次更新涉及五个文件：`index.html`、`.pages.yml`、`content.json`、`resources.json`、`README.md`。若通过 GitHub 上传，五个文件应一起提交到仓库最外层；后台配置更新后需刷新 Pages CMS 页面。

视频会占用仓库空间和访问带宽，建议先用小文件。GitHub 网页上传单文件不超过 25 MiB；Pages CMS 实际限制还取决于它的上传接口。[GitHub 文件限制](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github)

只能上传有权公开传播的资源。公开仓库中的文件不适合存放私人材料。

## 第一次接入：只做一次

### 上传五个文件

在 GitHub 仓库 `sharey99/sharey99.github.io` 的 **Code → Add file → Upload files** 上传以下五个文件，放在仓库最外层，并一次性提交到 `main` 分支：

- `index.html`：更新后的首页，替换原文件。
- `content.json`：全部网站收藏与笔记。首次接入需要上传，以后由后台维护。
- `resources.json`：书籍、图片、视频资源清单。
- `.pages.yml`：后台字段配置。文件名以英文点开头，不要漏传，也不要保存成 `.pages.yml.txt`。
- `README.md`：本说明，替换原文件。

首次上传应将这五个文件放到同一次提交，保证首页和数据同步更新。“临时文件”文件夹不上传。

原有 Pages 配置继续使用 `main` 与 `/ (root)`，无需更换网址。等待 GitHub Actions 中 Pages 部署成功后再访问网站。

### 登录并授权 Pages CMS

1. 打开 [https://app.pagescms.org/](https://app.pagescms.org/)。
2. 选择使用 GitHub 登录（界面按钮可能是 Sign in with GitHub）。
3. 按页面提示安装 Pages CMS 的 GitHub App。
4. GitHub 让你选择仓库时，选择 **Only select repositories（仅选择的仓库）**，只选 `sharey99.github.io`。
5. 阅读实际列出的权限并由你本人完成安装授权。该应用需要读取和写入仓库文件，才能把你填写的内容保存到 GitHub。
6. 返回 Pages CMS，打开账号 `sharey99`、仓库 `sharey99.github.io`、分支 `main`。
7. 它应读取 `.pages.yml`，出现 **“网站收藏与笔记”** 编辑入口。

如果提示缺少配置，先到 GitHub 仓库确认最外层能看到 `.pages.yml`。本版本采用合法 YAML 的 JSON 写法，无需手动转换格式，也不要另建一个空配置覆盖它。

Pages CMS 是独立的第三方服务，你的后台入口在它的网站。本版不创建 `sharey99.github.io/admin/` 页面。

## 以后怎么添加内容

### 新增网站、课程或视频链接

1. 登录 Pages CMS，进入“网站收藏与笔记”。
2. 在列表中添加一个新条目。
3. 填标题、分类、简介、收录日期。
4. 在“外部网址”粘贴 `https://` 开头的原始来源链接。
5. 标签、图标、颜色和角标可以选填，正文和附件可以留空。
6. 点击后台的保存按钮。保存会提交到 GitHub，并在下一次 Pages 部署完成后公开显示。

### 写自己的文章、心得、游戏攻略

1. 添加条目并填写标题、分类、简介和日期。
2. 在“文章正文”下添加段落，填写正文；小标题可选。
3. 一段正文可以粘贴多行文字，换行会保留；需要分章节时继续添加段落。
4. 可附原始来源链接或一个附件。文章存在正文时，首页先展开阅读，链接和附件位于文章底部。
5. 保存后等待部署，刷新网站查看。

正文是纯文本段落，不处理 HTML 或 Markdown 富文本。当前文章在弹窗中阅读，没有独立文章网址。

### 添加附件

在条目的“附件”字段选取或上传有权公开的小文件，后台将文件写入仓库 `files/` 中，并把路径填回条目。

一般收藏附件支持文档和常见位图；资源书架另外支持 MP4/WebM 视频。大视频不适合直接堆放到 Pages 仓库。公开仓库中的附件可以被任何人下载，不要上传私人或未经授权的材料。

一条内容至少填写 **外部网址、附件、文章正文** 三者之一。只有标题和简介的空条目不会显示。标题、分类、收录日期为必填。

### 编辑、删除与排序

- 打开已有条目即可修改；删除对应列表项后保存即可从首页移除。
- 列表顺序对应首页的“默认顺序”。首页也支持按日期或标题排列。
- 页面中的“示例文章”可直接替换为真实笔记，也可删除。
- 后台上传附件和删除内容都产生仓库提交，旧文件可能仍留在 Git 历史中。
- 后台保存内容后不要再拿旧版 `content.json` 覆盖上传，否则会覆盖新内容；需要本地备份时先从 GitHub 下载最新版。

## 发布与可见性

- 本配置直接保存到 `main`，不是私密草稿箱。公开仓库中的内容可在部署前就被看到。
- “保存成功”表示内容已写入 GitHub，不代表网页已经部署结束。到仓库 **Actions** 查看 Pages 部署状态。
- 刷新网页后应看到新内容；缓存未更新时可按 `Ctrl + Shift + R`。
- 后台配置已被站主成功打开。本次资源类型、文件显示、播放器及关闭行为通过本地验证；真实资源上传需使用你自己的文件。

## 哪些适合放，哪些需要授权

下面的发布建议以你拥有相关权利、符合适用规则为前提。公开可访问、免费、非营利或标明来源，都不是自动转载许可。

| 内容 | 建议发布方式 | 注意事项 |
| --- | --- | --- |
| 自己的笔记、心得、攻略 | 直接写在站内 | 不含他人隐私、保密信息；职务或受托成果先核对权利归属 |
| 网站、作者文章和视频 | 写自己的简介，链接原作者或官方页面 | 不绕过付费、登录等访问限制，不冒充来源 |

| 有权公开传播的 PDF、EPUB 和资料 | 小文件可提供附件，大文件用合适的平台 | 保留授权依据，核对文档内素材的权利 |

| 读书摘录和评论中的引用 | 以自己的理解为主，必要时适当引用并注明作者与作品 | 不用大段摘录替代原作；合理使用需结合具体情形判断 |
| 游戏截图、演示与素材 | 写自己的攻略，使用符合发行商政策的素材 | 不自动免授权；留意版本与剧透 |

### 本站不收录

- 未经授权的付费电子书、扫描书、课程搬运、影视和音乐文件。
- 盗版游戏、破解软件、盗用激活码、账号共享或泄露数据库。
- 明知用于提供上述侵权内容的网盘地址、种子、磁力链接和下载合集；只放链接也不自动免责。
- 他人身份证、私人聊天、未获同意的照片和联系方式，以及未授权公开的公司、客户资料。
- 恶意文件、钓鱼页面及其他违法内容。

买过一本电子书或一套课程，一般不等于取得向公众传播的权利。“仅供学习”“侵删”也不能替代授权。授权不明时，先只记录书名、作者和官方购买或阅读入口。

这些是本站收录原则，具体作品仍需核对适用法律和许可。关于权利归属、公开传播、适当引用，参见[国家版权局发布的《中华人民共和国著作权法》](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)。

### 视频、书籍、文件怎么放

- **别人发布的视频**：保存原作者在正规平台上的观看链接，不下载搬运；如需嵌入播放器，先确认平台规则。本版不预加载第三方播放器。
- **自己的视频**：上传至合适的视频平台，再添加链接，避免用 Pages 存大视频。
- **别人出版的书籍**：分享自己的书评、笔记及出版社或授权平台链接；未获许可不提供整本 PDF/EPUB。
- **自己编写且有权公开的文件**：小文件可放在仓库的 `files/` 中；大文件放到你有权使用的存储平台，再添加链接。
- **免费或公版资源**：保留来源并查看许可。Project Gutenberg 主要基于美国版权状态选书，不能据此认为每个版本在所有地区都可自由传播。[该项目版权说明](https://www.gutenberg.org/policy/permission.html)



## 隐私、权利与反馈

公开首页不设置 Cookie，不保存搜索词，不接收访客上传，不嵌入统计和广告脚本。GitHub 托管平台、Pages CMS 后台和外部链接各有自己的日志与隐私政策。后台只向有相应仓库权限的编辑者提供内容写入能力。

原创内容不默认授予整篇转载权；第三方内容遵守相应权利人的许可。本版没有替站主选择代码或文章的开放许可。

纠错入口为 [GitHub Issues](https://github.com/sharey99/sharey99.github.io/issues)，需仓库启用 Issues。请勿在公开反馈中填写敏感个人信息。
