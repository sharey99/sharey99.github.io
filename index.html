分享与版权说明

这里分享什么

网站导航、自己的笔记和攻略，以及资源书架中的书籍、图片和视频文件。链接不代表本站拥有资源版权或对其作出保证。

关于书籍、视频和文件

资源书架展示实际文件。只有拥有公开传播权，或符合明确授权与适用规则的文件，才适合上传。公开可访问、个人购买过或标注来源，都不自动等于可以转载。

不分享盗版书籍、付费课程搬运、破解软件、未经许可的影视与游戏文件，也不收录这些内容的网盘链接。

关于文章与示例

标为“示例文章”的内容用于展示页面结构，不代表站主真实经历或观点。其余原创内容的转载授权，以作者另行说明为准；第三方内容仍归相应权利人所有。

隐私与反馈

当前公开首页没有账号、评论、统计脚本、广告或文件上传功能。内容编辑使用独立的 Pages CMS 后台，后台适用其自己的账号与隐私规则。本站代码不设置 Cookie，也不保存搜索词。自我介绍中的大五人格结果由第三方 iframe 提供，加载时会连接 bigfivepersonality.me，适用其隐私规则。GitHub 托管平台及外部网站也可能有各自的日志与隐私政策。

发现失效链接或版权疑问，可通过 GitHub Issues 提交来源、问题页面与说明（需仓库启用 Issues）。请勿在公开反馈中填写身份证、住址等敏感信息。

更多维护方式与授权注意事项见 README.md。分享经验不构成对任何人的结果承诺。
